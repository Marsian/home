# 实现结果摘要

日期：2026-04-28

## 1. 新手村地图裁边与坐标对齐

- 逻辑网格由 **28×20** 调整为 **24×20**（左右各裁去 2 列外围草地）。
- 世界宽度 **1440px**（24×60）；高度 **1200px**（20×60）。
- 道路 `paintPath`、出生点 **`S`**、传送门格 **`P`**、地标 `cell`、hotspot 等格坐标 **整体 x −2**，与裁边一致。
- `starterVillageMap.portal` 与地图上 **`P`** 及传送门 hotspot 对齐为 **`(12, 3)`**；`start` 为 **`(12, 17)`**。

主要文件：`src/game-center/pixel-knight/game/maps/starterVillage.ts`

## 2. 地表补丁：草地 3×3 + 砖路

- 草地 `terrain-grass-field`：**3×3** 共 9 块 **480×480** 矩形铺满 **0..1440 × 0..1200**。
- 砖路：`terrain-brick-road-vertical` / `terrain-brick-road-horizontal`；道路 patch **x 世界坐标相对裁边前整体左移 120px**，与去掉两列草地一致。

主要文件：

- `starterVillage.ts`（`starterVillageTerrainPatches`）
- `rendering/villageAssets.ts`
- `assets/village/terrain/`

## 3. 村庄 HUD：`emitHud` 签名去重（home 阶段）

- `phase === 'home'` 时，对关键字段构造 **JSON 签名**；与上一轮相同则 **跳过** `onHud`，减少行走时 React 侧无效 setState。
- 非 home 阶段仍每次下发完整 HUD。

主要文件：`src/game-center/pixel-knight/pixelKnightGame.ts`

## 4. 移除村庄装饰层

- `starterVillageDecorAnchors` 为空；不再走村庄装饰独立渲染路径；**地标建筑与交互 hotspot 保留**。

## 5. 村庄静态地表离屏缓存

- 首次绘制村庄地表时，按 `starterVillageTerrainPatches` 包围盒 **bake** 离屏 canvas，之后按相机 `drawImage` 子矩形。
- 阶段/地图变化时 **清空缓存**，避免脏画面。

## 6. 资源生成脚本（非运行时依赖）

仓库内可选脚本（地形片、砖路等）例如：

- `scripts/generate-pixel-knight-terrain-patches.py`
- `scripts/build-pixel-knight-brick-road-from-seamless-tile.py`
- `scripts/generate-pixel-knight-brick-road-terrain.py`

## 7. 当前边界

本轮不包含：

- 迷宫/副本机制的新增需求（仍以 v1 开发记录为准）。
- 村庄环境音与传送门特效专项。
- 纵向再次裁切 `VILLAGE_ROWS`（留给后续迭代）。
