# 素材与布局规格

日期：2026-04-28

## 1. 地图与坐标系

| 项目 | 规格 |
| --- | --- |
| 逻辑格数 | **24 列 × 20 行** |
| 格尺寸（世界 px） | 60×60 |
| 世界宽高 | **1440 × 1200** px |
| 裁边说明 | 相对历史 28 列布局，**左右各去掉 2 列**纯草地；所有格坐标 **x −2** |

出生点格 **`S`**、传送门格 **`P`** 与 `MapDef.start` / `MapDef.portal`、各 hotspot `cell` 必须一致，避免小地图与交互错位。

## 2. 地表 patch（世界坐标）

草地使用 **`terrain-grass-field`**（单张资源 **480×480**，在矩形内 `repeat` 平铺）：

- 行、列各 3 块，覆盖 x ∈ {0, 480, 960}，y ∈ {0, 480, 960}，共 9 块。

砖路使用：

- `terrain-brick-road-vertical`：主竖向道路等。
- `terrain-brick-road-horizontal`：分支与横向段。

v4 封版时道路矩形 **x 起点相对 28 列时代左移 120px**（2×60），与裁边一致；具体数值以 `starterVillageTerrainPatches` 源码为准。

## 3. 地形素材目录

本轮村庄地表主要引用：

`src/game-center/pixel-knight/assets/village/terrain/`

| 资源（示例） | 用途 |
| --- | --- |
| `terrain-grass-field.png` | 草地 patch 平铺底 |
| `terrain-brick-road-vertical.png` | 砖路竖条 |
| `terrain-brick-road-horizontal.png` | 砖路横条 |

`villageAssets` 中仍可能登记其他地形或切片（如 dirt、plaza 类），**当前村庄地图 patch 以草地 + 砖路为主路径**；未在 `starterVillageTerrainPatches` 中引用的资源视为预留。

## 4. 类型与地图定义

- 地图行串长度须等于 **24**，行数 **20**（与 `VILLAGE_COLS` / `VILLAGE_ROWS` 一致）。
- 摄像机、`worldWidth` 等一般由 `rows[0].length * TILE` 推导；改列数时需同步检查地表 patch 包围盒与离屏缓存尺寸。
