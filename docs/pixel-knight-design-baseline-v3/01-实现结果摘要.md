# 实现结果摘要

日期：2026-04-27

## 1. 角色选择页

本轮将角色选择页从 CSS 拼装的临时实现，重构为基于像素图片素材的页面：

- 背景改为静态像素背景图 `character-select-bg-clean.png`。
- 顶部 title bar 使用独立 PNG 素材，贴到页面顶部，并左右顶边。
- 中央角色保留现有点阵角色 renderer 实时绘制，不使用效果图中的静态角色截图。
- `进入游戏` 按钮使用独立 PNG 按钮素材，放在中央角色下方，与角色展示形成同一操作组。
- 右侧角色列表使用独立角色卡片素材，包含 normal、focused、selected 状态。
- 角色列表只展示当前真实存在的骑士角色，其余槽位为空卡片。
- 卡片内删除了子职业、职业介绍、赛季、返回、删除角色和“新兵”等额外标记。

## 2. 角色渲染

本轮明确了两个渲染状态：

- 中央大角色：`idle`
- 角色列表头像：`static`

`static` 是本轮新增的 renderer mode，用于角色列表这类需要完全静止的 UI 场景。它会冻结 locomotion time，并关闭头部和身体的 idle bob，避免头像在列表内持续动。

中央大角色仍使用 `idle`，但移除了页面层面的 `actorFeetY` 呼吸偏移。脚底锚点保持固定，避免 idle 状态看起来像角色浮在空中。

## 3. 布局稳定性

本轮修复了多个比例和对齐问题：

- 中央角色 canvas 以 512x512 固有比例等比显示，不再被外层矩形容器横向拉伸。
- 角色选择页使用 `aspect-[1672/941]`，贴合概念稿和背景素材比例。
- loading/error 阶段也使用同一画幅，保证背景图和角色选择页定位一致。
- 右侧角色列表整体下移，避免与顶部 banner 视觉冲突。
- 角色列表卡片间距收紧，整体更接近概念稿。
- 角色列表右侧最终保留轻微边距：`right-[1.2%]`。

## 4. Loading 页面

loading overlay 现在复用角色选择页背景图：

- 背景图：`character-select-bg-clean.png`
- 图片 class 与角色选择页一致：`absolute inset-0 h-full w-full object-cover`
- 父容器画幅与角色选择页一致：`1672/941`
- 叠加轻微暗化层，保证 loading 文案和进度条可读。

## 5. 当前边界

本轮不包含：

- 角色本体像素画优化。
- 新职业创建流程。
- 角色装备外观扩展。
- 游侠、法师等未实现职业展示。
- 用静态截图替换现有点阵角色 renderer。
