## 2. 背景

角色选择页与 loading 页必须使用同一张背景、同一套定位规则：

```tsx
<img
  src={characterSelectBg}
  alt=""
  className="absolute inset-0 h-full w-full object-cover"
  draggable={false}
  style={{ imageRendering: 'pixelated' }}
/>
```

父容器使用 `aspect-[1672/941]`。如果父容器比例变化，`object-cover` 会产生不同裁切，导致 loading 和角色选择页背景定位不一致。

## 3. 顶部 Banner

顶部 title bar：

- 容器：`absolute left-0 right-0 top-0`
- 图片：`h-auto w-full`
- 标题文字覆盖在图片中心。

当前要求是 banner 顶到页面顶部，两边也靠边。

## 4. 中央角色

中央角色 canvas：

- canvas 内部尺寸：`512 x 512`
- CSS 显示：`mx-auto block h-full w-auto max-w-full`
- 绘制 mode：`idle`
- `actorFeetY` 固定，不叠加页面层呼吸位移。

该 canvas 必须等比显示，不能同时使用 `w-full h-full` 填满非正方形容器，否则会造成横向或纵向拉伸。

## 5. 角色列表

角色列表容器当前参数：

```tsx
className="absolute right-[1.2%] top-[21.5%] flex w-[33.2%] flex-col gap-[0.75vw]"
```

角色卡片：

- 宽高比：`aspect-[896/253]`
- frame 使用 PNG：normal/focused/selected
- hover/focus 对非选中、非空槽卡片切换 focused frame
- 空槽只显示空卡片，不渲染角色和文字

角色列表内的角色渲染：

- canvas 内部尺寸：`128 x 128`
- CSS：`absolute left-[6.7%] top-[13%] h-[67%] w-[18.8%]`
- mode：`static`
- `pixelSize: 5`
- `actorFeetY: 183`
- 通过 canvas 裁切只露出偏头部区域

注意：不能给角色列表头像额外添加角色没有的装备。当前只使用骑士已有的 sword/shield 配置。

## 6. 进入游戏按钮

按钮位置：

```tsx
className="group absolute left-[24.2%] top-[80.4%] aspect-[417/119] w-[25.2%]"
```

按钮文字作为真实 UI 文本渲染，不能烘焙进图片素材。按钮图片只承载边框、底色和像素质感。
