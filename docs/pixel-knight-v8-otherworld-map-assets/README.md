# Pixel Knight V8 Otherworld Map Assets

Dungeon selection map assets for the teleport point / otherworld map board.

## Files

- `concepts/otherworld-map-base-biomes.png`: base map board with varied biome sockets.
- `source-green/otherworld-entrances-front-greenscreen.png`: 10 entrance sprites, front-facing.
- `source-green/otherworld-entrances-right-greenscreen.png`: 10 entrance sprites, angled to the viewer's right.
- `source-green/otherworld-entrances-left-greenscreen.png`: 10 entrance sprites, angled to the viewer's left.

## Entrance Order

1. Volcanic forge gate
2. Frost peak shrine
3. Emerald ruin tower
4. Autumn spirit grove
5. Desert sun obelisk
6. Shadow crystal rift
7. Tropical tide cave
8. Ancient clockwork temple
9. Mushroom swamp hut
10. Sky altar portal

The entrance sheets use chroma-key green backgrounds for later cutout processing.
