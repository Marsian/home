日期：2026-04-22  
用途：将公开资料拆为“可借鉴事实”，为后续设计和实现提供可追溯依据

## 1. 使用说明

### 1.1 标记定义

- `保留`：结构和语义可直接沿用
- `改写`：保留功能或信息组织，但画法、命名、轮廓需要改写
- `舍弃`：不纳入首版
- `禁止直接复刻`：不可直接照搬图形或成品资产

### 1.2 `ReferenceMapping`

```ts
type ReferenceMapping = {
  source_link: string
  source_fact: string
  adoption_mode: '保留' | '改写' | '舍弃' | '禁止直接复刻'
  modification_note: string
}
```

## 3. 单角色入口映射

| 来源 | 可确认事实 | 采用 | 处理说明 |
| --- | --- | --- | --- |
| BWiki《职业》 | 职业分为子职业和混合职业 | 保留 | 作为“当前角色需要明确职业身份”的事实依据，但首版不在入口页提供创建和切换 |
| BWiki《职业》 | 混合职业由两个子职业组合 | 改写 | 仅保留为后续成长系统背景，不进入单角色入口页 |
| BWiki《职业》 | 存在多个基础子职业列表 | 改写 | 首版缩减为单个固定角色，只保留职业展示语义 |
| wiki.gg《Classes》 | 基础职业在角色创建界面选择 | 舍弃 | 首版直接砍掉角色创建流程，不照搬原作创建入口 |
| wiki.gg《Classes》 | 额外基础职业在早期等级阶段开放选择 | 舍弃 | 不在首发入口页承载职业扩展信息 |
| 原作职业卡与职业像素形象 | 具备明确外框、职业头像与 icon 体系 | 禁止直接复刻 | 若保留当前角色卡语义，也不得直接照搬卡框和像素角色成品 |

## 4. 村庄映射

| BWiki《NPC》 | 功能性 NPC 交互后会弹出一段对话，随后进入某个界面 | 保留 | 固定为村庄核心交互语法 |
| BWiki《NPC》 | 秋梨村存在铁酱、铁匠、铁心、996便利店、宝箱商人、卡片商人、洗点商人、宝石商人、铃铛商人、巴托斯、瓦力、特利斯坦、银灵婆婆等功能入口 | 改写 | 作为“功能 NPC 应该分散承载高频系统”的事实依据；Pixel Knight 需改写 NPC 命名、造型与招牌 |
| wiki.gg《996 Combini》 | 村庄商店位于世界地图传送口上方 | 改写 | 借鉴“高频商店靠近副本入口”的布局思路，不直接复刻原始村庄位置关系 |
| wiki.gg《996 Combini》 | 商店支持购买装备 / 药水、出售物品、回购已出售物品、按品级批量出售 | 保留 | 为村庄商店和背包快捷动作提供系统事实依据；批量出售作为后续扩展预留 |
| 原作秋梨村完整街区画面 | 具有可识别的路网、建筑立面、NPC 阵列 | 禁止直接复刻 | 只保留“Hub 组织方式”，禁止做地图截图式复刻 |

## 5. 背包 / 状态映射

| 来源 | 可确认事实 | 采用 | 处理说明 |
| --- | --- | --- | --- |
| BWiki《强化》 | 强化依附铁匠功能，作用于装备、武器、饰品属性、攻击力 / 法术强度、词条 | 保留 | 背包详情页和装备入口必须预留强化、词条相关入口 |
| BWiki《强化》 | 强化需要金币 | 保留 | 在强化入口旁保留货币语义和成本展示位 |
| BWiki《强化》 | 强化存在成功率变化与等级上限 | 改写 | 作为“强化是独立成长子系统”的依据；首版文档先保留入口，不强绑原作数值规则 |
| wiki.gg《996 Combini》 | 商店出售装备和药水，也支持卖出和回购 | 保留 | 背包右键动作需要预留出售 / 回购相关语义 |
| 公开 FAQ / 攻略类资料中的礼包、暂存、邮件等入口认知 | 玩家习惯通过村庄或系统窗口处理未领取物件 | 改写 | 首版只保留邮箱 / 公告 / 临时暂存语义，不扩展活动背包 |
| 原作背包整窗卡框、格子、分页图标 | 拥有成熟三栏式或多区块信息展示 | 禁止直接复刻 | 保留“纸娃娃 + 背包格 + 属性详情”的组织，不照搬具体边框和图标 |

## 6. 首版明确舍弃项

| 来源 | 可确认事实 | 采用 | 处理说明 |
| --- | --- | --- | --- |
| BWiki《职业》 | 部分子职业通过蓝宝石或赛季黄金手册解锁 | 舍弃 | 首版不引入运营货币与赛季付费入口 |
| 各类赛季、活动、限定系统 | 存在运营期扩展玩法 | 舍弃 | 本轮明确排除活动界面 |
| 原作活动广场、节庆布置、运营入口 | 会改变 Hub 负载和视觉重心 | 舍弃 | 村庄只保留主功能组织，不预留节庆 UI 区 |

## 8. 验收口径

- 每条“参考原作”的内容都能追溯到公开资料链接
