# 实现结果摘要

日期：2026-04-29

## 1. HUD 状态框

- 左上角 HUD 改为像素美术状态框，包含头像区、HP 槽与 MP 预留槽。
- HP 与 MP 条体位于背景框和前景框之间：`hud-status-frame-v2.png` 为底图，`hud-status-frame-front-v2.png` 为压在条体之上的前景框。
- HP 非满状态使用素材裁切，不缩放条体比例；MP 本轮固定显示 `100/100`，仅验证蓝条视觉效果。
- 状态框使用 `clamp` 与比例容器，支持随游戏区域自适应缩放。

主要文件：

- `src/game-center/pixel-knight/PixelKnightView.tsx`
- `src/game-center/pixel-knight/assets/ui/inventory/hud-status-frame-v2.png`
- `src/game-center/pixel-knight/assets/ui/inventory/hud-status-frame-front-v2.png`
- `src/game-center/pixel-knight/assets/ui/inventory/hud-hp-fill-core-v2.png`
- `src/game-center/pixel-knight/assets/ui/inventory/hud-blue-fill-core-v2.png`

## 2. 右上角 HUD 与小地图

- 小地图实时 SVG 作为底层，像素框 `hud-minimap-frame-v2.png` 作为上层覆盖；框体内容窗口保持透明。
- 地图 SVG 使用固定窗口铺满，不再在框内留下明显 padding。
- 地图名移动到小地图标题区；左上角不再显示旧地图信息卡片。
- `Run Feed` 面板移除；交互提示改为底部临时 plaque。
- 背包按钮使用像素素材 `hud-backpack-button-v2.png`，与小地图大框上沿对齐。

## 3. 背包面板

- 背包覆盖范围为游戏容器内 `absolute inset-0`，不覆盖页面标题、站点导航或浏览器视口。
- 左侧为角色与装备槽区域，装备槽只有一套：项链、戒指、主手在左侧；头盔、盔甲、副手在右侧。
- 右侧背包固定为单一 6×6 grid，不再叠加第二套格子或重叠面板。
- 角色下方展示台已移除，角色直接站在背包主面板空间内。
- 底部统计区与角色、装备槽对齐，并针对大屏放大图标与字号。

主要文件：

- `src/game-center/pixel-knight/PixelKnightView.tsx`
- `src/game-center/pixel-knight/assets/ui/inventory/inventory-bg-v2.png`
- `src/game-center/pixel-knight/assets/ui/inventory/inventory-grid-6x6-v2.png`
- `src/game-center/pixel-knight/assets/ui/inventory/inventory-slot-v2.png`

## 4. 装备数据与背包交互

- 装备系统从历史 `weapon / shield` 迁移为 `mainHand / offHand`。
- 项链与戒指槽保留，但当前不生成对应物品。
- 当前 demo 仅生成和保留已有点阵定义的装备：`cloth-cap`、`iron-helmet`、`iron-armor`、`iron-sword`、`wood-shield`。
- 点击背包物品可装备；点击已装备槽位可卸下，卸下物品进入背包最后一格。
- 已装备物品 hover 显示详情弹窗；背包格 hover 只显示贴合格子的描边与物品 tooltip。

主要文件：

- `src/game-center/pixel-knight/content/data.ts`
- `src/game-center/pixel-knight/profile.ts`
- `src/game-center/pixel-knight/types.ts`

## 5. 角色装备同步

- `PixelKnightView` 将 `profile.equipment` 解析为 `MatrixEquipmentPiece` 后同步给 `PixelKnightGame`。
- `PixelKnightGame` 移除固定装备常量依赖，村庄与副本角色使用当前玩家装备。
- 背包角色、村庄角色、副本角色都使用同一套装备数据，因此铁盔、铁甲、主手、副手的外观一致。

主要文件：

- `src/game-center/pixel-knight/PixelKnightView.tsx`
- `src/game-center/pixel-knight/pixelKnightGame.ts`

## 6. 当前边界

本轮不包含：

- 新增项链或戒指的真实装备物品与角色挂点。
- MP / 法力 / 能量 gameplay 字段。
- 背包排序、拖拽、堆叠、出售、分解等完整物品管理功能。
- 页面级全屏；Pixel Knight 语境下的“全屏”仍指游戏容器内全屏。
