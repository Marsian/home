# 素材与布局规格

日期：2026-04-29

## 1. HUD 素材

| 资源 | 用途 |
| --- | --- |
| `hud-status-frame-v2.png` | 左上角色状态框底图 |
| `hud-status-frame-front-v2.png` | 左上角色状态框前景框，覆盖在 HP / MP 条上方 |
| `hud-hp-fill-core-v2.png` | HP 红条核心素材，非满状态裁切显示 |
| `hud-blue-fill-core-v2.png` | MP 蓝条核心素材，当前固定满值显示 |
| `hud-minimap-frame-v2.png` | 右上小地图像素框，内容窗口透明 |
| `hud-backpack-button-v2.png` | 右上背包按钮 |
| `hud-pause-button-v2.png` | 暂停按钮框 |
| `hud-prompt-plaque-v2.png` | 底部交互提示框 |

状态框的关键层级：

1. `hud-status-frame-v2.png`
2. HP / MP fill
3. `hud-status-frame-front-v2.png`
4. 数字文字

HP 与 MP 条体必须保留点阵比例；非满状态通过裁切实现，不允许直接横向压缩素材。

## 2. 小地图布局

- 小地图窗口位于 frame 内部，实时地图 SVG 在底层。
- frame 素材放在上层，以保证地图不会覆盖边框。
- 地图窗口背景色可用于填补 SVG 内容不足区域。
- 地图名显示在 frame 标题条内。

## 3. 背包布局

背包 overlay 只覆盖游戏容器：

- 根层：`absolute inset-0`
- 背景框：`inventory-bg-v2.png`
- 左侧角色与装备区：约占游戏容器左半区
- 右侧背包 grid：固定 6×6，共 36 格

装备槽布局：

| 位置 | 槽位 |
| --- | --- |
| 左上 | 项链 |
| 左中 | 戒指 |
| 左下 | 主手 |
| 右上 | 头盔 |
| 右中 | 盔甲 |
| 右下 | 副手 |

统计区位于装备槽与角色正下方，当前基线位置：

- `left-[12.5%]`
- `top-[67%]`
- `w-[42%]`
- `grid-cols-4`
- 大屏通过 `lg` / `xl` 增大图标、标签和数值字号。

## 5. 统计图标

统计图标目录：

`src/game-center/pixel-knight/assets/ui/inventory/stats/`

包含：

- `attack.png`
- `armor.png`
- `health.png`
- `crit-chance.png`
- `crit-damage.png`
- `skill.png`
- `move-speed.png`
- `gold.png`

v5 基线要求统计图标为纯色点阵 PNG，不带木框，不使用 CSS 伪造图标。

## 6. 空槽 placeholder

空槽 placeholder 目录：

`src/game-center/pixel-knight/assets/ui/inventory/placeholders/`

包含：

- `helmet.png`
- `armor.png`
- `main-hand.png`
- `off-hand.png`
- `amulet.png`
- `ring.png`

v5 基线要求 placeholder 为生成 PNG 资产，不使用 canvas 手绘；风格为简洁灰色点阵轮廓，不模仿具体已存在装备。

## 7. 可渲染装备 catalog

当前唯一可渲染装备 catalog：

| assetId | 槽位 |
| --- | --- |
| `cloth-cap` | `helmet` |
| `iron-helmet` | `helmet` |
| `iron-armor` | `armor` |
| `iron-sword` | `mainHand` |
| `wood-shield` | `offHand` |

掉落生成、存档 normalize、背包格渲染与角色外观同步均以该 catalog 为准。
