# 角色选择首页迭代记录

日期：2026-04-24  
模型：`gpt-image-2`

## 1. 迭代背景

本轮目标是基于《元气骑士前传》一类像素 ARPG 菜单的清爽感，重新探索 Pixel Knight 的角色选择首页效果图。用户明确要求只生成效果图供 review，不直接开发页面。

## 2. 关键反馈

第一轮方向存在问题：

- 页面加入了返回功能，但当前角色选择页本身就是首页。
- 页面展示了职业介绍，但当前选择的是用户创建好的已有角色，不需要职业说明面板。
- 整体视觉过于浮夸和繁复，与参考图的干净像素风不一致。

第二轮方向改善后，继续修正：

- 角色列表中每个角色都需要显示头像，不能使用盾牌代替。

第三轮方向确定最终布局：

- `进入游戏` 按钮移动到和当前角色展示平行的区域，放在角色下方，与角色主视觉形成同一操作组。

## 4. 最终采纳点

- 页面无返回入口。
- 页面无职业介绍面板。
- 页面无删除角色入口。
- `进入游戏` 主按钮移动到当前角色下方，与角色展示形成同一视觉组。
- 右侧角色列表每项显示职业头像。
- 当前展示职业限定为骑士、游侠、法师。
- 整体保持明亮、简洁、低装饰密度。

## 5. 后续待定

- 是否存在角色创建流程及其入口位置。
- 角色名、等级、职业名的真实字段来源。
- 当前选中角色是否需要 idle 动效。
