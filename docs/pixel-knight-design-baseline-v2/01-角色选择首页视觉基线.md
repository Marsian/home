# 角色选择首页视觉基线

日期：2026-04-24  
推荐图：`concepts/character-select-home-clean-v3.png`

## 1. 设计目标

角色选择首页需要在进入游戏前完成一个清晰决策：玩家从已有角色中选中一个角色，然后进入游戏。

视觉上以清爽、明亮、易读为优先，不追求复杂装饰、重叠面板或强烈特效。页面应该像一个已经可玩的像素 ARPG 首页，而不是角色创建宣传页。

## 2. 画面结构

- 顶部：深色像素标题栏，居中显示 `选择角色`。
- 主视觉：中左区域展示当前选中角色的大像素立绘。
- 列表区：右侧纵向展示已有角色，每个角色一张独立列表卡。
- 操作区：`进入游戏` 按钮与当前角色展示区域绑定，位于角色下方或同一视觉组内。
- 背景：明亮户外像素场景，作为轻量氛围，不抢角色和列表焦点。

## 3. 角色列表

角色列表是本页最重要的信息区之一，必须满足以下要求：

- 每条角色记录必须显示对应职业头像。
- 头像应使用头肩像素小头像，不使用通用盾牌、徽章、职业图标或抽象占位符。
- 当前选中角色使用浅黄色高亮底，未选中角色使用低饱和浅灰或半透明浅底。
- 列表中优先展示角色名、职业名和等级。
- 当前基线只展示骑士、游侠、法师三个已存在职业，不展示未上线职业。

## 4. 当前角色展示

- 当前角色站在画面中左区域，比例明显大于列表头像。
- 角色姿态保持静态待机感，可预留轻微 idle 动效空间。
- 武器和服装用于表达职业身份，但不应遮挡角色脸部和主要轮廓。
- 大角色与右侧列表之间保留足够留白，避免拥挤。
- `进入游戏` 按钮应贴近当前角色主视觉，强化“使用该角色进入游戏”的关系。

## 5. 色彩与像素质感

- 主背景：浅蓝天空、绿色地形、暖色阳光，整体明亮。
- 标题栏：深灰或深棕，压住顶部信息层级。
- 选中态：浅黄色或暖金色，强调但不刺眼。
- 主按钮：暖黄色，和选中态形成同一操作语言。
- 描边：深色像素描边，厚度稳定，避免软阴影和玻璃质感。

## 6. 禁止项

- 不使用返回按钮。
- 不展示职业介绍、主属性、起始武器、战斗定位等说明面板。
- 不加入赛季、活动、商城、公告等运营入口。
- 不使用过度华丽的边框、发光、宝石、卷轴、复杂纹样。
- 不把角色头像替换为盾牌、徽章或职业 icon。
- 不把 `进入游戏` 放成远离角色的独立全局底栏按钮。
