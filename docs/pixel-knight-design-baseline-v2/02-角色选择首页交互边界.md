# 角色选择首页交互边界

日期：2026-04-24  
适用范围：角色选择首页后续实现

## 1. 页面职责

本页是游戏首页，承担三个职责：

- 展示当前可进入游戏的已有角色。
- 切换当前选中的角色。
- 点击 `进入游戏` 后进入游戏主流程。

除此之外的创建角色、删除角色、职业详情、职业解锁、赛季入口、活动入口，都不属于当前基线范围。

## 2. 可交互元素

### 2.1 角色列表

- 单击角色卡：切换当前选中角色。
- 当前选中角色：保持高亮。
- 空列表状态：本基线暂不定义，需要后续结合真实创建流程单独设计。

### 2.2 进入游戏

- 单击 `进入游戏`：使用当前选中角色进入游戏。
- 无可用角色时：按钮应禁用或进入空态流程，本基线暂不展开。

## 3. 不提供的交互

- 不提供返回上级。
- 不提供删除角色入口。
- 不提供角色创建入口。
- 不提供职业说明弹窗。
- 不提供职业详情展开。
- 不提供赛季或永久切换。

## 4. 状态要求

- 默认态：自动选中列表第一位角色。
- 选中态：列表卡高亮，大角色展示同步更新。
- 悬停态：可轻微提亮角色卡，但不改变布局尺寸。
- 按下态：角色卡或主按钮有短暂压下反馈。
- 禁用态：无可用角色时主按钮不可点击。

## 5. 实现注意

效果图是视觉基线，不应额外推导出未确认功能。实现时优先复用当前项目已有角色数据结构，只在样式和布局上对齐本基线。
