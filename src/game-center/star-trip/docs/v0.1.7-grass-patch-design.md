# V0.1.7 Spawn Grass Patch

日期：2026-05-28

V0.1.7 只处理出生点附近草地观感。目标不是全星球铺草，而是在出生点附近放一块可验收的成熟草地样例，验证后续生态区细化方案。

## 参考方案

- 视频：Dylearn《How I made grass better than 99% of games | Stylized grass 3D pixel art》
- 示例项目：https://github.com/DylearnDev/Dylearn-3D-Pixel-Art-Grass-Demo
- 附件截图：Waterfowl 的像素化草地宣传图，用于校准绿色噪点底色、草叶密度和低分辨率画面气质。
- 本轮已用 `yt-dlp` 获取视频缩略图和 `00:20-00:35` 片段帧，作为实现校准材料，输出在 `output/star-trip/v0.1.7/reference-video-*.png`。

Dylearn 方案的核心是两层：底部 floor shader 用世界坐标噪点在 3 个草色之间分区；上层草叶使用透明像素贴图 billboard，通过实例 ID 和世界坐标噪点产生颜色、尺寸和风摆差异。风动画按 5fps 阶梯化，避免高帧率平滑动画破坏像素风。

## 本轮结论

- 不应该在地面 shader 里自由绘制“草叶线条”。参考项目的草形状来自 `Grass.gdshader` 对透明草叶贴图的 quad 采样，地面 `Floor.gdshader` 只负责三色噪声底色。
- 也不应该用少量草叶实例假装草坪材质。`Demo.tscn` 在 `25 x 25` plane 上使用 `visible_instance_count=30000`，说明草形视觉主要来自密集 billboard grass quad 层。
- 不能把参考密度无条件搬到当前球面近景相机。直接折算到 `24000` 或 `12000` 个透明 billboard 会遮挡角色/道具，且在 headless SwiftShader 下拖慢移动测试。最终 `6000` 个主草叶在视觉和性能之间更稳定。
- 草叶和地皮必须共享同一套颜色分区和光照，否则即使分区算法相同，也会看起来像两层不协调的绿。最终版本把地面三色收敛到同一基绿附近，并在实例生成时预计算草叶颜色分区。
- 像素化等级不应该改变草地着色。渲染路径已统一为始终经过 pixel render target 和 screen pass，避免 `pixelationLevel=0` 与非零等级出现亮度差。

## 当前迁移

- 复用 Dylearn 的 `grassleaf.png` 与 `accentleaf.png`，保存在 `assets/textures/grass/v0.1.7/`。
- `game/grassPatch.ts` 不再生成椭圆覆盖 mesh，而是把出生点附近的草地 shader 直接安装到 `ST016_planet_terrain_shell` 的材质上；草地边界通过地形片元里的软噪点 mask 过渡。
- 地面材质严格按 `Floor.gdshader` 的职责实现：只用世界坐标噪声在 `albedo1/albedo2/albedo3` 三种草色之间分区，不包含时间项，也不生成流动草纹。
- 地面参数来自 `Demo.tscn`：`albedo2_scale=0.11`、`albedo2_threshold=0.537`、`albedo3_scale=0.1`、`albedo3_threshold=0.471`，颜色也按场景文件中的 `Color(...)` 值迁移。
- 草形状不在地面 shader 里自由绘制；参考项目的草形来自 `Grass.gdshader` 对 `grassleaf.png` / `accentleaf.png` 的透明 quad 采样。
- 参考 `Demo.tscn` 在 `25 x 25` plane 上使用 `visible_instance_count=30000`、`QuadMesh size=Vector2(0.2, 0.3)`；当前球面近景相机不能直接套同一屏幕密度，折算为 `6000` 个主草叶 quad 和 `1` 个低频 accent quad，避免贴图层整片遮挡玩家和道具，并保持移动测试性能。
- 草叶 shader 使用相机 billboard、世界坐标噪点、两路风噪组合、`0.365` 风噪阈值和 `5fps` 阶梯时间，迁移参考 shader 的贴图朝向和风摆节奏；玩家靠近时会轻微推开草叶。
- 草叶颜色与地皮共用同一套 `patchUv`、`fbm`、`albedo2/albedo3` 阈值和地表法线 toon lighting，因此同一位置的 grass quad 会跟地面三色分区保持一致；该分区在实例生成时预计算，避免每帧在 6000 个草叶顶点上重复计算。三色都收敛在同一个绿色基色附近，只保留小幅明暗/冷暖变化。风摆位移比初版更强，但仍保持阶梯化像素风。
- 草地材质直接替换 terrain shell 的局部着色，因此不会漏出原始地貌贴图，也不会出现独立覆盖物的硬边。

## 最终参数

- patch center: `lat=-18.3`、`lon=22.8`
- patch radius: `x=14.2`、`z=11.4`
- main grass quads: `6000`
- accent grass quads: `1`
- quad size range: width `0.17-0.23`、height `0.26-0.38`
- wind frame rate: `5fps`
- wind threshold: `0.365`
- wind displacement: `0.5 * instanceHeight * uv.y^2`
- final screenshot: `output/star-trip/v0.1.7/spawn-grass-final-muted-matched-6000.png`

## 验收

- `npm run test:e2e -- e2e/star-trip.spec.ts`
- 结果：`10 passed`
- E2E 断言会检查 `grassPatch.version`、`proceduralGround`、草叶实例数和 accent 数，防止后续回退成无草地或少量贴图点缀。
