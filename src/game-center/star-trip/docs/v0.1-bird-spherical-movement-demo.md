# V0.1 小鸟球面移动 Demo

日期：2026-05-20

V0.1 是 `a star trip` 的第一版可玩 demo。它不再是概念展示页，而是一个放在游戏中心面板里的 Three.js 小型可玩场景，用来验证小鸟快递员 Pico 在球面星球上的角色建模、基础移动、镜头观察和出生场景气质。

## 版本目标

- 将 `/games/star-trip` 从全屏概念画面改为游戏面板内的实际 demo。
- 以小鸟星际快递员作为主角方向，回归《A Short Hike》式的亲切轮廓，同时保留红围巾、喷气背包和快递员身份。
- 验证角色在球面星球表面移动时，姿态和动作是否能像站在巨大地面上一样自然。
- 建立出生点附近的最小场景：坠毁火箭、草坡、小池、树石、路径和远处通讯塔。
- 明确 V0.1 不做 HUD、任务、收集、NPC、种植、钓鱼、音频或存档。

## 已实现内容

- 页面结构：
  - `StarTripView.tsx` 只负责 Back 按钮、居中固定比例 playfield 和 runtime mount/dispose。
  - 游戏内容限制在 `aspect-[16/10]` 面板中，不再铺满整个 viewport。
  - 面板内没有可见 HUD、教程文字、状态计数器、概念说明或调试 UI。
- 主角 Pico：
  - v0.1.1 起使用 Blender MCP 生成并导出的 glTF/GLB 模型，不再使用 Three.js primitive 角色。
  - 当前形象是低多边形小鸟，包含侧面眼睛、尖鸟喙、蓝色衣服、整体翅膀和连续腿脚。
  - 角色动画状态包含 `walk`、`run`、`jump`、`jet`、`glide`，不再保留单独 `idle`。
  - 根节点姿态由球面地面系统独占控制，动画只作用于 GLB 模型与关键子节点。
- 球面移动：
  - 星球半径为 `13.6`，相对角色尺度比概念 demo 明显增大，为后续更多地形和角色预留空间。
  - 每帧构建局部地面坐标系：`up` 为星心到角色的法线，`forward/right` 为该法线上的正交切平面。
  - 角色世界 `Y` 轴始终对齐星球法线。
  - 角色前进方向始终位于当前切平面内。
  - 跳跃、喷气和下落沿局部 `up` 轴处理。
- 控制方式：
  - `W` / `ArrowUp`：沿角色当前面向前进。
  - `S` / `ArrowDown`：沿角色当前面向后退。
  - `A` / `ArrowLeft`、`D` / `ArrowRight`：原地踏步转向，不横向平移。
  - `Shift`：跑步。
  - `Space`：跳跃；空中按住可触发短喷气/滑翔状态。
  - 鼠标/指针拖拽：只移动相机视角，不改变角色面向。
  - 鼠标滚轮：调整第三人称镜头距离。
- 镜头：
  - 第三人称可调视角，不是固定镜头。
  - 默认中远距离观察，能同时看到角色和出生点周边环境。
  - 相机 orbit 与角色朝向解耦；拖动相机不会带动角色转身。
  - 镜头基于角色所在地表法线平滑校正 horizon，避免剧烈翻转。
- 出生场景：
  - 大球面草地、暖土 patch、浅路径、小池、树、石头、低矮坡面。
  - 坠毁火箭和散落零件作为出生点叙事锚点。
  - 远处通讯塔只作为视觉目标提示，不提供交互和抵达目标。
  - 已移除星环，因为星环不属于当前设计概念。

## 技术结构

主要运行时代码位于 `src/game-center/star-trip/game/`：

- `starTripGame.ts`：Three.js runtime 入口，负责 scene、renderer、camera、resize、RAF、dispose 和 e2e hook。
- `planetMath.ts`：球面坐标、法线、切平面、局部地面三轴和表面对齐工具。
- `playerModel.ts`：加载并规范化 Pico GLB 模型，建立关键部件 pivot。
- `playerAnimation.ts`：Pico 子部件动画。禁止修改角色根节点姿态。
- `playerController.ts`：输入语义、球面移动、转向、跳跃、喷气、滑翔和法向对齐。
- `cameraRig.ts`：第三人称相机 orbit、pitch、zoom 和 horizon 校正。
- `input.ts`：键盘输入状态。
- `spawnEnvironment.ts`：出生点附近地形与装饰物。

测试位于 `e2e/star-trip.spec.ts`，通过 `?e2e=1` 使用 `window.__starTrip_e2e.getSnapshot()` 读取运行时状态。该 hook 不渲染任何可见 UI。

## 验收标准

V0.1 当前满足以下标准：

- `/games/star-trip` 打开后看到的是游戏面板中的可玩场景，而不是全屏概念宣传页。
- Pico 能被识别为小鸟星际快递员，且红围巾和喷气背包清楚可见。
- 玩家能在出生区域附近走、跑、原地转向、跳跃、短喷气和滑翔。
- 鼠标调整视角不会改变角色面向。
- 左右键不会横向平移，而是通过原地踏步调整角色朝向。
- 角色模型的上方向与星球法线严格一致，角色前方向保持在切平面内。
- 星环已移除。
- 星球相对角色尺度足够大，不再像只能摆几个物件的小球。
- 游戏面板内部只有游戏内容。

## 自动化验证

已通过：

```bash
npm run build
npx playwright test e2e/star-trip.spec.ts
```

Star Trip e2e 覆盖：

- playfield 位于游戏面板内，比例稳定。
- 面板内无 HUD/概念说明文本。
- canvas 非空。
- 前进移动不会滚动页面。
- 角色前进、模型姿态和星球法线关系正确。
- 左右键原地转向，不横向位移。
- 鼠标拖拽只改变相机，不改变角色 forward。
- 滚轮能调整相机距离。

## 当前不做

- 不做能量块收集和喷气背包升级。
- 不做 NPC、对话、任务、交易或日程。
- 不做种植、钓鱼、图鉴、物品栏。
- 不做音频、动态音乐或存档。
- 不做完整星球生态带，只保留出生点附近风景。
- 不做移动端虚拟摇杆；移动端当前只保证布局和相机触控基础可用。

## 后续建议

- V0.1 后续小修优先继续打磨手感：转向动画节奏、加速度、跳跃高度、滑翔姿态和镜头距离。
- V0.2 再引入能量块与喷气背包成长，但仍应保持 HUD 极少或无 HUD。
- 在扩展地形前，先保证所有新地形资产都遵守同一套球面法向和局部地面坐标规则。
