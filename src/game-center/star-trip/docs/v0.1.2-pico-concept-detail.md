## 生成方式

本轮优先使用 Blender MCP 做场景读取和迭代验证；实际 GLB 导出时，MCP 上下文触发了 Blender glTF 插件的 `active_object` 上下文限制，因此将可复现生成逻辑沉淀为：

```bash
/Applications/Blender.app/Contents/MacOS/Blender --background --python scripts/star-trip/create-pico-v012-assets.py
```

脚本会打开 V0.1.1 `.blend`，创建 V0.1.2 细节对象，另存 `.blend`，导出 `.glb`，渲染 Blender 三视图，并写入 `.check.json`。

## 游戏接入

- `playerModel.ts` 改为加载 `pico-v0.1.2-detail.glb`。
- 运行时 `materialPalette` 增加喷气背包材质并同步新蓝色。
- 原 `Pico_Debug_JetFlame` 替换为 `Pico_Jetpack_Flames` group，包含左右两个喷口火焰，位置由 GLB 中 `Pico_Jetpack_Nozzle_L/R` 的 bounds 推导。
- e2e snapshot 暴露 `picoAsset.detailObjectsPresent`，用于确认运行时实际加载了 V0.1.2 细节对象。

## 动作与飞行手感

本轮也收敛了 Pico 在起跳、喷气和滑翔之间的运行时姿态语义：

- `jump` 和 `jet` 共用原地起飞姿态：躯干不再单独位移或前后点头，只保留双臂/翅膀微张和轻微腿部姿态。
- `playerAnimation.ts` 新增 `PicoPose` 目标姿态混合。动画每帧从上一帧渲染姿态平滑追向当前目标姿态，避免 `jet -> jump -> glide` 状态切换时出现肢体硬切。
- `glide` 的前倾作用在 Pico GLB 根节点上，而不是只旋转躯干，因此头部、背包、尾巴、手臂、腿和喷气火焰会随整体姿态一起移动。
- V0.1.2 当前滑翔前倾角为 `0.6` 弧度，用于增强空中读图。
- 滑翔和喷火不互斥：
  - `jetActive` 只控制喷气背包火焰显示和向上推力。
  - `gliding` 只控制滑翔姿态、空中前进速度和滑翔重力。
  - 只要 Pico 在空中、高度超过 `MIN_GLIDE_ALTITUDE`，且玩家按住前进键，就进入滑翔姿态；如果同时按住 `Space` 且还有喷气时间，则保持火焰和上升推力。

## 微调记录

在概念细节初版后，按目力验收方向做了一次 Blender MCP 微调：

- 背包贴近角色背部并上移到头部略低的位置，移除背包 panel/buttons。
- 尾巴改为向后下垂。
- 三撮毛改为沿头部中轴线前中后分布的 mohawk 形态。
- 脚部在原腿脚 mesh 内单独分配 `Pico_Foot_OrangeYellow` 材质。
- 躯干改为柔和新潮宇航员感配色，不添加新元素。

第二次目力微调：

- 背包 Z 轴高度进一步缩短，并向角色背部内推，和躯干背面轻微相交以避免视觉空隙。
- 三撮毛改为三角锥形，并整体移动到脑后方向形成头部后侧轮廓。

第三次目力微调：

- 尾巴根部抬回躯干末端，同时保持下垂方向以避开喷口。
- 后两撮头发重新按头部后上方轮廓压入头皮，避免悬空。
- 躯干色系切换为淡薰衣草紫，底部色块切换为柔和霓虹粉。

收尾脸部微调：

- 鸟嘴根部在 Z 轴方向加厚，保持尖鸟嘴轮廓。
- 左右眼白和瞳孔略微放大，并沿角色前方轻微前移。
