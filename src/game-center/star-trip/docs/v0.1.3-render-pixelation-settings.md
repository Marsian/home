# V0.1.3 像素化渲染与配置面板

日期：2026-05-22

V0.1.3 是 `a star trip` 在 Pico 角色模型稳定后的第一轮渲染风格改造。本轮目标是把 A Short Hike 式的低分辨率像素化输出接入当前 Three.js demo，并提供一个最小配置入口，让玩家可以在清晰画面和像素化画面之间切换。

## 版本目标

- 仿照 A Short Hike 的核心像素化方法：低分辨率渲染目标 + nearest/point 放大 + 无抗锯齿。
- 像素化强度必须可调，并且可以完全关闭。
- 配置 UI 不进入游戏 HUD 体系，只在右上角提供齿轮入口。
- 设置面板只配置像素化幅度，保持当前 v0.1 demo 的无 HUD 气质。

## A Short Hike 参考结论

本轮调研确认 A Short Hike 的公开资料基本指向同一技术路线：

- 游戏使用低分辨率输出、无抗锯齿和平面化视觉语言，让 3D 场景呈现像素感。
- Adam Robinson-Yu 在 PlayStation Blog 中提到低分辨率是核心美术选择，并提供 pixel size 偏好调整。
- MobyGames credits 记录 A Short Hike 使用 Unity 与 GBCamera。
- GBCamera 的公开说明是 Unity camera setup + custom shader；GDC 转述资料描述为主相机输出低分辨率 RenderTexture，再由另一个相机显示，并使用 Point filter。
- A Short Hike 的精确源码参数没有公开；玩家和评测资料可确认它提供有限的 pixel size 档位，而不是连续精细参数。

## 已实现内容

### 像素化渲染管线

主要实现位于 `src/game-center/star-trip/game/starTripGame.ts`：

- 新增 `StarTripRenderSettings`，当前只有 `pixelationLevel`。
- 新增 `WebGLRenderTarget` 作为低分辨率渲染目标。
- render target texture 设置：
  - `magFilter: THREE.NearestFilter`
  - `minFilter: THREE.NearestFilter`
  - `generateMipmaps = false`
  - `colorSpace = THREE.SRGBColorSpace`
- 像素化开启时：
  1. 将主 scene 渲染到低分辨率 render target。
  2. 使用 full-screen quad 把该 texture 放大回主 canvas。
- 像素化关闭时：
  - 维持原来的 `renderer.render(scene, camera)` 直接输出路径。
- render target 尺寸基于 playfield 的 CSS 尺寸计算，不乘设备 DPR，避免高 DPR 屏幕削弱像素化效果。

### 四档像素化幅度

当前档位为固定 0-3：

- `0px`：关闭像素化。
- `1px`：最轻像素化。
- `2px`：默认档位。
- `3px`：当前最大像素化。

最初实现曾使用 0-7 档，但在当前 Star Trip 面板尺寸下，`3px` 已经有很强的像素化表现，因此收敛为更接近 A Short Hike 的固定档位体验。旧 localStorage 中如果存在更大的值，会自动 clamp 到 `3px`。

### 配置面板

主要实现位于 `src/game-center/star-trip/StarTripView.tsx`：

- playfield 右上角新增齿轮 icon button。
- 点击后在 playfield 内展开近全屏配置 panel。
- 面板标题为“配置”，不显示副标题。
- 关闭按钮与标题上边沿对齐。
- 面板当前只有一个配置项：`像素化幅度`。
- 配置通过 range input 在 `0px` 到 `3px` 之间切换。
- 设置持久化到 `localStorage`：
  - key: `star-trip-render-settings-v1`
- 面板打开时：
  - React 配置 UI 保持高分辨率清晰显示，不参与像素化。
  - pointer / wheel / keyboard 事件不会穿透到游戏 canvas 或相机拖拽。
  - 面板获得焦点；关闭后焦点回到游戏 canvas。

### E2E Hook

`window.__starTrip_e2e.getSnapshot()` 新增：

- `renderSettings.pixelationLevel`
- `pixelation.enabled`
- `pixelation.blockSize`
- `pixelation.targetWidth`
- `pixelation.targetHeight`

这些字段用于确认配置 UI 和渲染管线实际联动，而不是只检查 DOM 状态。

## 已知限制

- 当前只有像素化幅度配置；没有加入图像质量、阴影、轮廓、色彩校正等选项。
- 当前像素化是全画面后处理，不做 per-object pixel stabilization。
- 当前没有引入 edge detection / outline 后处理；A Short Hike 的柔和轮廓效果后续可以作为独立版本继续补。
- 配置面板仍是 Star Trip 页面内局部 UI，不是全站通用设置系统。

## 下一步建议

- 在 v0.1.4 或后续视觉版本中尝试轻量 outline / edge detection，让低像素画面里的远处物体更易读。
- 结合当前 `WebGLRenderTarget + screen quad` 管线继续接入 color correction，形成更完整的 Star Trip 渲染风格。
- 在移动端进一步验证 1px/2px/3px 档位的可读性，必要时为小屏单独调整默认档位。
