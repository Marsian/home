# V0.1.1 Pico Blender MCP / GLB 角色建模

日期：2026-05-21

V0.1.1 是 `a star trip` 在 V0.2 玩法开发前的角色建模与资产管线迭代。目标不是增加新玩法，而是把 V0.1 的 Three.js primitive Pico 替换为可在 Blender 中持续编辑、可通过 glTF 导入游戏的正式角色资产。

## 版本目标

- 保留当前 React/Vite + Three.js 技术栈，不迁移 PlayCanvas。
- 引入 Blender 作为 Pico 的正式模型编辑工具。
- 通过 Blender MCP 生成和迭代第一版低多边形 Pico 模型。
- 将 `.blend`、`.glb` 和资产检查报告纳入 Star Trip 项目目录。
- 在游戏运行时加载 GLB Pico，不再保留 primitive Pico fallback。
- 将本次 MCP 建模经验沉淀为项目内 skill，方便后续 NPC/角色批量建模。

## 已交付内容

### 角色资产

资产位于 `src/game-center/star-trip/assets/models/characters/pico/`：

- `pico-v0.1.1-blockout.blend`：Blender 可编辑源文件。
- `pico-v0.1.1-blockout.glb`：Three.js 运行时加载资产。
- `pico-v0.1.1-blockout.check.json`：导出检查报告。

当前 Pico 是低多边形小鸟 blockout：

- 大头短身比例。
- 侧面圆片眼睛。
- 尖鸟喙。
- 蓝色衣服/躯干。
- 一体连续 mesh 的腿脚。
- 一体连续 mesh 的翅膀/胳膊。
- 暂时不包含围巾和背包，避免在基础比例未稳定前加入额外复杂度。

### Blender MCP Skill

项目内新增 `src/game-center/star-trip/skills/blender-mcp-character/`：

- `SKILL.md`：MCP 建模工作流、连接方式、安全边界。
- `references/character-blockout.md`：低多边形角色建模经验、比例/几何/命名规范。
- `scripts/call_blender_mcp.py`：当 Codex 会话没有直接暴露 Blender MCP tool 时，通过 `uvx blender-mcp` stdio 调用 MCP 的辅助脚本。

本 skill 的核心经验：

- 先在 Blender 中生成可人工编辑的 `.blend`，不要绕过 Blender 直接生成最终游戏资产。
- 紧密连接的肢体优先使用连续 mesh 和多段环线，而不是多个独立方块靠近拼接。
- 对需要摆动的 limb，在运行时用 pivot wrapper 或后续正式骨骼控制；pivot 应由模型几何推导，避免写死在旧比例上。
- 导出前后用 MCP 检查对象名、mesh 数量、材质、骨骼占位和 stale object 残留。

### 游戏接入

运行时代码仍位于 `src/game-center/star-trip/game/`：

- `playerModel.ts`
  - 使用 `GLTFLoader` 异步加载 `pico-v0.1.1-blockout.glb`。
  - 校验必需对象名，GLB 缺失时抛出可诊断错误。
  - 按包围盒归一化模型高度。
  - 将 GLB 材质替换为运行时 palette 的 `MeshBasicMaterial`，保证游戏内颜色稳定。
  - 为腿脚和翅膀建立 pivot wrapper，便于运行时基础动画。
- `playerAnimation.ts`
  - 保留 `walk`、`run`、`jump`、`jet`、`glide`。
  - 移除 `idle` 状态；静止时不再呼吸上下晃动。
  - walk 中腿部摆幅略增，翅膀按前后方向摆动。
- `playerController.ts`
  - 继续只控制角色 root 的球面移动、位置和朝向。
  - 静止时保持 `walk` 的基础姿态，但速度为 0，因此没有 idle 动画表现。
- `starTripGame.ts` / `StarTripView.tsx`
  - 支持异步创建游戏实例。
  - 修复 React StrictMode 下旧异步实例可能清理新 e2e hook 的问题。
  - 模型加载失败时在 playfield 内显示明确错误。

## 技术决策

- 运行时继续使用 Three.js，因为 V0.1 的球面移动、相机、输入和 e2e hook 已围绕 Three.js 建立。
- Blender 是角色源文件的事实来源，`.blend` 用于人工微调，`.glb` 用于运行时。
- Blender MCP 用于生成初稿、工程化整理、导出和检查；最终比例、轮廓和审美判断仍由人工在 Blender 中完成。
- 当前 GLB 仍是 blockout，不追求最终权重、正式骨骼动画和完整材质管线。

## 验收结果

已通过：

- `npm run build`
- `npx playwright test e2e/star-trip.spec.ts`

Playwright 覆盖：

- Star Trip 面板和 canvas 渲染。
- 移动不滚动页面。
- 左右键原地转向而非横向平移。
- 球面法线对齐。
- 摄像机拖拽 orbit 和滚轮距离。

## 已知限制

- 当前 armature 仍是占位，运行时动画主要使用对象 pivot wrapper，不是正式 skinned mesh 动画。
- 当前模型是 blockout，仍需要在 Blender 中继续人工微调比例、五官、轮廓和衣服细节。
- 当前没有围巾、背包、NPC 变体，也没有正式动画 clips。
- 材质颜色在运行时由 palette 强制控制；后续如果建立正式 toon 材质/贴图管线，需要同步更新导出检查与运行时材质替换策略。
