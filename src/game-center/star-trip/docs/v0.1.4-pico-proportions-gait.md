# V0.1.4 Pico 比例与步态校准

日期：2026-05-22

V0.1.4 是 Pico 角色稳定后的第一轮身体比例和地面步态修正。本轮只处理两个目标：让 Pico 的躯干略短、腿更长；让 walk/run 的实际位移速度与腿部摆动距离一致，减少贴地移动时的漂移感。

实现完成后又补了一次 walk/run 衔接修正：walk 与 run 不再使用两套按 `elapsed` 直接计算的正弦相位，而是共享一个连续累积的 gait phase。角色从走到跑时，腿部动作会逐渐加快、摆幅逐渐变大，不再出现切换瞬间的腿部跳变。

## 比例调整

v0.1.4 从 `pico-v0.1.2-detail.blend` 派生，核心对象名保持不变，方便运行时继续按名字查找部件。

检查报告记录的比例变化：

- 躯干高度：`0.88 -> 0.7568`，约 `-14%`。
- 腿部高度：`0.525 -> 0.6457`，约 `+22.99%`。
- 两腿之间的横向间距：`0.086 -> 0.156`，增加 `0.07`。
- 左右腿中心从原本靠近中轴的位置拉到 `x = -0.147 / 0.147`，更贴近两侧胯部。
- 左右腿顶部与躯干下沿 overlap：`0.035`。
- 尾巴根部上移并嵌入新躯干后下端，`tail_reaches_lower_torso` 和 `tail_embedded_in_rear_torso` 均为 `true`。

## 运行时校准

`playerModel.ts` 现在加载 `pico-v0.1.4-proportions.glb`，并根据腿部 bounds 自动建立腿部 pivot，替代旧的固定 pivot 坐标。

`playerAnimation.ts` 集中定义 walk/run gait：

- walk: `angularSpeed = 7.5`，`legSwing = 0.58`
- run: `angularSpeed = 11`，`legSwing = 0.68`
- `visualStepLength = 2 * effectiveLegLength * sin(legSwing)`
- `cadence = angularSpeed / PI`
- `speed = visualStepLength * cadence`

`playerController.ts` 使用这套 gait speed 作为地面 walk/run 的目标速度，保留原有加速度平滑。跳跃、喷气和滑翔速度不在本版本调整范围内。

## Walk/Run 衔接

初版 v0.1.4 的速度已经来自 gait metrics，但动画仍然根据 mode 直接切换步频：

- walk 使用 `elapsed * 7.5`
- run 使用 `elapsed * 11`

这会导致 mode 一旦从 walk 变成 run，腿部正弦相位瞬间重算，视觉上出现突变。

最终实现改为：

- `playerAnimation.ts` 用 `WeakMap<PicoParts, number>` 保存每个 Pico 实例的连续 `gaitPhase`。
- 每帧根据当前速度在 walk/run 的 `angularSpeed` 与 `legSwing` 之间 `smoothstep` 插值。
- `gaitPhase += blendedAngularSpeed * delta * activeAmount`，phase 只前进，不因 mode 切换重新计算。
- 腿和翅膀都使用同一条连续 phase，只改变频率和摆幅。

因此 walk 到 run 的衔接表现为自然加速，而不是切换到另一套动画。

## 已知限制

- 本版本没有调整跳跃、喷气、滑翔的速度或姿态。
- gait 校准仍是基于简化步距公式，不是完整 foot contact / IK 系统。
- 当前没有专门的视觉回归视频；视觉验收依赖 Blender 三视图、运行时 Playwright 覆盖和人工观察。
