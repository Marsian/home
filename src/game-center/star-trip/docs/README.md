# star-trip docs

这个目录用于区分稳定的 concept 设计文档与后续开发过程中的版本文档。

- [concept](./concept/README.md)：当前 concept baseline，包含调研笔记、核心企划、美术/角色/音乐方向和阶段路线图。
- [v0.1-bird-spherical-movement-demo.md](./v0.1-bird-spherical-movement-demo.md)：V0.1 第一版可玩 demo 说明，记录小鸟主角、球面移动、镜头控制与出生场景范围。

后续版本开发文档可以放在本 README 同级，例如 `v0.1-movement-demo.md`，或新建 `versions/` 目录，避免和最初的 concept baseline 混淆。
