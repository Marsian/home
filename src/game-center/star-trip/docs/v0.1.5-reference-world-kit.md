# V0.1.5 Reference World Kit

日期：2026-05-25

V0.1.5 是 Star Trip 第一轮星球基础素材建设版本。本轮最初尝试覆盖大批自然物、地标和地貌，但实际验收后发现“有参考来源”不等于“素材精细度已经贴近参考”。最终版本收缩范围，只保留能在公开页面找到明确参考对象的 24 个资产，并把建模重点转向单件完成度。

本版本的目标不是复制 A Short Hike 的原始模型、贴图或场景布局，而是对齐它的低多边形完成度：清楚的剪影、足够的部件数量、大块 flat color、无需纹理也能读懂的功能性物件。

## 资产范围

最终保留 24 个 reference-backed assets：

- Nature 5：`ST015_star_pine`、`ST015_round_canopy_tree`、`ST015_short_grass_a`、`ST015_pebble_cluster`、`ST015_low_rock`
- Landmark 13：`ST015_tower_keeper_cabin`、`ST015_utility_storage_shed`、`ST015_rope_bridge`、`ST015_tiny_pier`、`ST015_fishing_kid_shore_shed`、`ST015_beacon_lighthouse`、`ST015_campfire_ring`、`ST015_rocket_main_hull`、`ST015_rocket_side_fin_debris`、`ST015_scorch_mark_base`、`ST015_summit_comm_tower`、`ST015_signal_dish`、`ST015_wooden_way_sign`
- Terrain 6：`ST015_moon_bay_pool`、`ST015_pale_water_edge`、`ST015_beach_arc`、`ST015_warm_dirt_path`、`ST015_climbable_slope`、`ST015_summit_round_peak`

被移除的上一轮泛参考资产不再出现在 manifest、check JSON、运行时摆放或生成脚本分类集合中。

## Reference Manifest

新增 reference manifest：

```text
src/game-center/star-trip/assets/models/world/v0.1.5/world-v0.1.5-reference-manifest.json
```

每个资产记录：

- `assetId`
- `referenceType`
- `sourceUrl`
- `referenceObject`
- `targetFidelity`
- `originalizationRule`

主要参考来源：

- A Short Hike MobyGames 截图库：小屋、桥、湖、沙滩、灯塔、山路等对象类型。
- Wikimedia A Short Hike screenshot category：树、森林和路线环境参考。
- Steam 商店截图：整体低多边形山地氛围参考。
- NASA Mercury-Redstone 公开页面：Star Trip 火箭的公开参考。
- Wikimedia radio tower 图片：通信塔和信号设备参考。

## 建模调整

相比上一轮大范围粗覆盖，本轮重点加厚单件模型：

- 小屋/棚屋：加入地基、屋檐、台阶、窗台、双窗、烟囱等部件。
- 桥/码头：加入独立木板、木桩、侧栏和绳索。
- 灯塔：加入门、窗槽、观景环、顶盖和灯体。
- 营火：加入灰烬底、石圈、交叉木柴、多层火焰。
- 火箭：加入鼻锥、色带、窗、面板线、折损尾翼和喷口。
- 通信塔：加入基座、横梁、后支撑、天线、碟面和 beacon。
- 地貌 patch：水面、岸线、沙滩、路径、坡面和山顶都增加边缘石、草簇或颜色层级。

运行时会隐藏 GLB 中仅用于 contact sheet 审计的 `reference_label` 对象，避免它们进入游戏画面。

## 运行时接入

`PLANET_RADIUS` 从 `13.6` 扩大到 `40.8`，即直径扩大 3 倍。

新增 `starTripWorldAssets.ts` 作为 world asset registry：

- 从 check JSON 和 manifest 合并资产定义。
- 计算 collision radius、biome tags 和 reference metadata。
- 只摆放当前 24 个 reference-backed assets。

`spawnEnvironment.ts` 改为通过 `GLTFLoader` 加载 `world-v0.1.5.glb`，然后按 asset root 克隆到球面坐标。E2E snapshot 新增环境 summary，用于验证：

- asset definition 数量
- placement 数量
- reference 完整性
- missing asset ids
- 关键地标存在
- 球面径向距离和 up 对齐

## 已知限制

- 本轮仍是程序化低多边形建模，不是逐张截图做 image-plane tracing；它更接近“参考对象驱动的原创低模 kit”，不是逐像素复刻。
- 资产数量被刻意缩小，后续扩展新素材前应先补明确 reference，再建模。
- contact sheet 目前只展示本轮资产和 reference 类型标签，还没有生成逐资产 side-by-side 参考截图板。
