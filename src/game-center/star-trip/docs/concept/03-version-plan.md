# 03. 版本计划

## V0.0：项目入口与概念验证

状态：已启动。

目标：

- 建立 `/games/star-trip` 入口。
- 建立 `src/game-center/star-trip/docs` 企划目录。
- 用 Three.js 做一个球面星球概念画面，验证低多边形卡通 + 星球地图的第一印象。
- 在入口中展示坠毁火箭、山顶通讯塔、能量块、喷气背包成长和 NPC 交换四个核心方向。

交付：

- `StarTripView.tsx`
- `StarTripThumbnail.tsx`
- 企划文档初稿

验收：

- 项目能通过 TypeScript 构建。
- 游戏中心能看到 `A STAR TRIP` 卡片。
- 打开 `/games/star-trip` 能看到球面星球概念画面。

## V0.1：球面移动 Demo

目标：验证“在球面星球表面走路”是否好玩且不晕。

范围：

- 一个可控制的 Pico 占位角色：小鸟轮廓、红围巾、喷气背包。
- 球面重力与贴地移动。
- 跳跃、跑步、短喷气起飞、滑翔。
- 摄像机跟随、自动校正 horizon、避免剧烈翻转。
- 2-3 个可到达地标：坠毁火箭、小池、低处山路、通讯塔远景。

技术任务：

- 建立 `game/` 子目录：scene、playerController、planetMath、cameraRig。
- 使用 Three.js raycast 或数学球面约束实现贴地。
- 添加 Playwright 截图测试，保证 canvas 非空、入口无明显遮挡。

验收：

- 玩家能绕星球走一圈并回到起点。
- 连续移动 3 分钟不产生明显眩晕。
- 所有主要地标从远处可见或可被发现。

## V0.1.1：Pico Blender MCP / GLB 角色建模

状态：已完成。

目标：在 V0.2 玩法开发前，将 V0.1 的 primitive Pico 替换为 Blender 可编辑、GLB 可运行时加载的正式角色资产管线。

范围：

- 配置并验证 Blender MCP 工作流。
- 在 Blender 中生成 Pico 低多边形 blockout。
- 将 `.blend`、`.glb` 和检查报告纳入项目资产目录。
- 新增项目内 `blender-mcp-character` skill，沉淀 MCP 角色建模经验。
- Three.js 运行时通过 `GLTFLoader` 加载 Pico GLB，不保留旧 primitive fallback。
- 移除 `idle` 状态，保留 `walk`、`run`、`jump`、`jet`、`glide`。

验收：

- 游戏中可见有颜色的 GLB Pico。
- 角色 root 仍由球面移动系统控制。
- 静止时没有 idle 上下晃动。
- walk 中腿部和翅膀有基础步行动作。
- `npm run build` 和 Star Trip e2e 通过。

## V0.2：喷气背包与能量块

目标：让球面星球有“走偏路也值得”的基础回报，并验证能量块提升飞行能力的主循环。

范围：

- 散落能量块拾取物。
- 3 个隐藏小物件。
- 2 档移动能力升级：喷气高度提升、滑翔续航提升。
- 通讯塔启动进度 UI。
- 简易手绘星图 UI，只显示已发现地标。

验收：

- 玩家不看任务文本，也能自然发现至少 2 个收集物。
- 获得能力后，玩家能抵达一个之前看得到但到不了的位置。
- 能量块同时被理解为“背包升级”和“通讯塔供电”。

## V0.3：种植系统

目标：验证轻养成是否能改变探索路径。

范围：

- 3 块可种植地。
- 3 类种子：风芽、夜灯花、水棉。
- 浇水/等待/成熟/采收。
- 成熟植物改变环境：风芽产生上升气流，夜灯花照亮夜路，水棉恢复钓鱼点。
- 作物可用于和至少 1 个 NPC 交换能量块或能量块线索。

验收：

- 种植反馈能在 5 分钟 demo 内看见。
- 种植不是菜单行为，玩家需要在世界中亲自抵达地块。
- 至少一个植物能影响移动或探索。

## V0.4：钓鱼系统

目标：做出低压力、有手感的钓鱼循环。

范围：

- 抛竿、等待、咬钩、拉线、成功/脱钩。
- 6 种鱼，按水域和时段区分。
- 鱼类图鉴。
- 钓鱼孩童 NPC，给第一根钓竿和一个短目标。

验收：

- 第一次钓鱼 30 秒内能理解。
- 稀有鱼有线索，不靠纯随机。
- 钓鱼能服务能量块交换或 NPC 关系，但不是强制刷材料。

## V0.5：NPC 生活与任务

目标：让星球显得不是围着玩家转。

范围：

- 3 个 NPC 的日程：白天/黄昏/夜晚位置不同。
- 对话系统：闲聊、任务、状态反馈。
- 2 条短任务线：帮忙找火箭零件、用鱼/作物交换能量块。
- 简易关系变量：帮助后改变称呼、位置或赠礼。

验收：

- NPC 至少有一个“玩家没触发也会发生”的移动/作息变化。
- 任务不依赖长篇文本，目标可以通过地点和物件理解。

## V0.6：音乐与声音

目标：建立 `a star trip` 的听觉身份。

范围：

- 生成或临时制作主题音乐占位。
- 行走、拾取、种植、钓鱼、对话音效。
- 基础动态音乐：靠近花园/水域/通讯塔时淡入不同层；喷气和滑翔时加入轻风声层。

验收：

- 主题音乐可循环 3 分钟以上不烦躁。
- 音乐层切换不突兀。
- 关键音效有视觉对应，便于无声游玩。

## V0.7：垂直切片

目标：形成 15-20 分钟可完整体验的 demo。

范围：

- 一个完整球面星球区域。
- 1 个主目标：收集足够能量块，抵达并启动通讯塔第一段。
- 3 个 NPC。
- 探索、能量块收集、种植、钓鱼、NPC 交换都有最小闭环。
- 开头、阶段完成、demo 结束三个叙事节点。

验收：

- 新玩家能在无开发者讲解下完成。
- 体验时长 15-20 分钟。
- 至少出现一次“我想去那边看看”的自发行为。

## V1.0：短流程完整版本

目标：完成 90-150 分钟主线，4-6 小时完整收集体验。

范围：

- 完整回声星。
- 5-7 个生态/地标区域。
- 8-12 个 NPC。
- 20-30 个能量块/小物件收集点。
- 12-18 种鱼。
- 10-14 种植物。
- 终局：抵达山顶通讯塔，联系母星并解锁尾声。

验收：

- 主线可在 2 小时左右完成。
- 不强迫全收集也能看到完整结局。
- 全收集有额外尾声和世界变化，但不是数值堆叠。

## V1.1+：扩展方向

可选扩展：

- 节气/天气：流星雨、薄雾清晨、暖雨。
- 拍照/星图：从特定角度观察星座和地貌。
- 小型建造：只允许修复或摆放少量营地物件，避免变成建造游戏。
- 二周目散步模式：保留植物和关系，取消主线压力。

暂不做：

- 战斗系统。
- 大型背包经济。
- 随机生成星球。
- 联机。
- 真实时间强绑定的农场日程。
