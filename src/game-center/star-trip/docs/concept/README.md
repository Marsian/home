# star-trip docs

`a star trip` 是一个短流程、小开放世界、轻养成的 3D 卡通探索游戏。玩家扮演一只小鸟星际快递员，小火箭坠毁在陌生星球上，需要收集能量块、升级滑翔喷气背包，最终抵达山顶通讯塔联络母星。项目入口位于 `/games/star-trip`，当前入口是一个用于验证美术方向、星球尺度和核心体验语气的 Three.js 球面星球概念 demo。

## 当前开发目标

先把基础体验验证清楚：一个球面星球是否能支撑自由探索、喷气背包成长、能量块收集、种植养成、钓鱼和 NPC 交换；低多边形/像素化 3D 材质是否能在浏览器内保持可读、舒适、轻盈；小鸟快递员是否能继承《A Short Hike》的亲切轮廓，但具备自己的星际快递员身份。
