# 01. 游戏企划

## 一句话概念

`a star trip` 是一个发生在小星球上的短流程 3D 探索游戏：玩家扮演一只圆脑袋猫星际快递员，小火箭坠毁在陌生星球上，通讯装置损坏。唯一能联络母星的设备在山峰顶端的通讯塔。玩家需要用带滑翔功能的喷气背包探索星球，收集散落或由 NPC 持有的能量块，逐步提升飞行能力，最终抵达通讯塔并发出救援信号。

## 核心体验

- 从坠毁点抬头就能看到远处山顶通讯塔。
- 玩家一开始飞不高，但能滑翔、绕路、寻找较低路线。
- 每个能量块都意味着更强的起飞高度、更远的滑翔距离和更多可达地点。
- 能量块大部分散落在星球上，一部分需要和 NPC 交换物资、帮忙或完成小挑战。
- 种植、养成、钓鱼不是另一个游戏，而是交换物资、认识居民、获得能量块线索的方式。
- 结局不是宏大拯救，而是一次终于接通的电话：母星听见了，救援会来。

## 世界设定

星球名暂定为“回声星”。它很小，表面由数个可步行生态带组成：

- 坠落草坡：玩家小火箭的坠毁点，作为安全起点和早期教学区。
- 星港村：几位本地居民活动的核心区域，也是交易、种子、钓竿的早期来源。
- 月湾池：钓鱼主区域，部分 NPC 会用能量块交换稀有鱼或水边材料。
- 暖壤园：种植主区域，玩家可以培育可交易作物，也能让 NPC 改变日程。
- 风铃脊：中段攀登区域，验证喷气背包升级后的高差路线。
- 山顶通讯塔：终极目标所在地，需要足够飞行能力和足够能量块启动。
- 背阳坡：偏安静的区域，有夜间 NPC、稀有植物、隐藏能量块和轻谜题。

地图不是平面岛屿，而是完整球面。玩家绕星球一圈能回到起点；远处目标会因为曲率慢慢从地平线升起。山顶通讯塔需要一直作为可见地标存在，像《A Short Hike》的山峰一样提醒玩家“我最终要去那里”。

## 主角与开局

主角暂名为“Pico”。Pico 是一只脑袋圆圆的猫形星际快递员，有像人类一样的四肢，可以跑、跳、攀爬、滑翔和钓鱼。Pico 的小火箭在送件途中被流星雨擦过，迫降到回声星。火箭主体还在，但通讯装置坏了，燃料也不足以重新起飞。

Pico 身上唯一可用的装备是快递员喷气背包：

- 初始状态：只能短促喷气起跳，随后进入滑翔。
- 升级方式：拾取能量块，提高最高起飞能力和滑翔续航。
- 叙事功能：能量块既是能力成长材料，也是最后启动通讯塔的能源。
- 情绪功能：玩家每拿到一块，都能感觉“我离回家更近了一点”。

## 终极目标

抵达山顶通讯塔并联系母星。通讯塔已经很久没人使用，需要一定数量的能量块才能启动。玩家不需要收集全部能量块才能通关，但需要达到两个门槛：

- 飞行门槛：喷气背包高度足以抵达山顶路线的最后几段。
- 启动门槛：通讯塔需要足够能量块供电，才能发出救援信号。

达到最低门槛即可触发结局。额外能量块可以解锁更完整的通话内容、更多 NPC 告别对白、修复火箭内部小部件或尾声后的自由探索状态。

## 核心循环

1. 看到目标：一块发光能量块、一个更高平台、一位移动中的 NPC、一片可钓鱼水域。
2. 抵达目标：步行、跳跃、短喷气、滑翔、绕球面找坡道。
3. 发现互动：拾取能量块、种植作物、钓鱼、帮 NPC 一个小忙、交换物资。
4. 获得回报：背包飞行能力提升、通讯塔启动进度、鱼类图鉴、NPC 关系、路线记忆。
5. 世界反馈：NPC 改变日程，作物成熟，某条捷径可用，通讯塔灯光逐步亮起。

## 系统设计

### 探索与移动

- 基础动作：走、跑、跳、攀爬低台阶、短喷气起跳、滑翔。
- 成长动作：喷气高度提升、滑翔续航提升、短暂停空、风道借力。
- 探索门槛主要使用“高度和距离”而非锁门：看到能量块但暂时飞不到，是最重要的驱动力。
- 地图不使用大地图标点，改用可视地标、居民描述、背包里的快递路线便签。

### 能量块

- 散落能量块：放在可见但需要探索的地点，鼓励绕路、攀爬和滑翔。
- NPC 能量块：居民手中持有，通常来自旧机器、灯塔仓库、钓鱼奖品或收藏。
- 交易需求：鱼、作物、矿石、小物件、短任务回报。
- 双重用途：提升喷气背包；最后为通讯塔供电。
- 设计原则：能量块数量要多于通关所需数量，避免玩家卡死或被迫全收集。

### 种植与养成

- 种植不走高强度农场模拟路线，而是“少量地块 + 明确视觉反馈 + 交易用途”。
- 作物可用于和 NPC 换能量块、鱼饵、路线线索或小道具。
- 部分植物也能改变环境：风芽产生上升气流，夜灯花照亮背阳坡，水棉净化小池。
- 成长周期以现实游玩时长计算，demo 阶段可压缩到 2-5 分钟。
- 不设置惩罚性枯萎，最多进入休眠，需要浇水或等天气恢复。

### 钓鱼

- 钓鱼是放松节奏点，也是交换经济和 NPC 关系的入口。
- 基础操作：抛竿、等待水面/线缆反馈、轻量拉扯、收杆。
- 鱼类由地点、天气、时段、鱼饵决定。稀有鱼应被暗示，而不是靠低概率折磨玩家。
- 鱼可放生、登记、赠送、换取材料。关键鱼登记后仍保留图鉴，避免玩家焦虑。
- 至少一个能量块需要通过钓鱼相关交换获得，但不应要求重复刷鱼。

### NPC 生活

首批 NPC 方向：

- 通讯塔看守：已经退休，知道塔还能启动，但把电池借给别人修过旧机器。
- 种子商人：推着小车绕星球走，会用能量块换稀有作物和肥料。
- 钓鱼孩童：把鱼当作星座命名，给玩家第一根钓竿，并持有一块钓鱼奖章能量块。
- 慢跑邮差：提供环星路线挑战，也和 Pico 产生同行职业的亲近感。
- 夜间天文学家：白天睡觉，夜晚观测背阳坡的星痕，知道几块隐藏能量块的位置。

每个 NPC 至少有：日程、停留点、一个短任务或交换需求、一个无任务闲聊池、与背包升级/通讯塔进度相关的一句反馈。

## Demo 验证范围

当前入口已经验证：项目命名、路由、3D 小星球视觉、低多边形卡通方向、拖拽旋转星球、坠毁火箭、山顶通讯塔、能量块和猫快递员喷气背包概念。

下一步 demo 需要验证：

- 第三人称猫角色在小球面上的移动是否舒服。
- 喷气背包从“只能短起飞”到“能抵达高处”的成长是否直观。
- 镜头在球面行走和滑翔时是否眩晕。
- 小星球大小是否能容纳 3-5 分钟有效探索。
- 一个种植点、一个钓鱼点和一个 NPC 交换是否能共同指向能量块目标。
