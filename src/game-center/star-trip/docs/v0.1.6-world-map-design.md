# V0.1.6 World Map And Terrain Design

日期：2026-05-26

V0.1.6 将 Star Trip 的小星球从 v0.1.5 的“参考素材陈列”推进到“可游玩的迷你开放世界地图”。目标是在较小球面上建立足够丰富的地貌对比，同时保持玩家直觉：高处变冷、低处有水、水边有沙滩或湿地、危险地带用颜色和形状提前提示。

## 参考原则

- A Short Hike：官方开发回顾强调 tiny open world、登山目标、路外探索奖励，以及低分辨率下仍可读的 flat shading 和轮廓。参考来源：https://blog.playstation.com/2021/08/05/crafting-a-tiny-open-world-a-look-behind-the-scenes-at-the-creation-of-a-short-hike/
- Breath of the Wild：地貌分析强调 triangle approach、上坡/绕路选择、谷地引导和从高处揭示远方目标。参考来源：https://www.gamedeveloper.com/design/breath-of-the-wild-open-world-analysis-gravity-to-go-forward
- Breath of the Wild open-air：Nintendo making-of 资料用于参考远景地标和“少 HUD、靠环境引导”的方向。参考来源：https://www.nintendo.com/en-gb/News/2017/March/Go-behind-the-scenes-with-the-making-of-The-Legend-of-Zelda-Breath-of-the-Wild-1206592.html

## 星球结构

最终目标是北侧雪线以上的 `ST016_summit_comm_array`。它被放在 `ST016_snow_cap_peak` 上，作为玩家从出生草地、湖岸和山脊都能理解的远方目标。

生态区覆盖：

- `spawn-meadow`：金色草地、坠毁探测器、树丛和营地灯，作为安全起点。
- `crater-lake`：中心低洼湖泊、环形岸线和桥，承担视觉中心与主路汇流。
- `beach-reef`：沙滩、潮池、礁架和浮标，满足“水边有沙”的直觉。
- `marsh-cave`：湿地、芦苇、蘑菇和隐藏洞口，提供路外奖励。
- `moon-dunes`：月面沙丘，用干燥低地制造色彩和节奏变化。
- `crystal-ridge`：晶体脊与三角岩墙，承担 BOTW 式“爬上去或绕过去”的阻挡与揭示。
- `ember-field`：灰烬地、热喷口和玄武岩，作为风险路线。
- `snow-summit`：雪峰、冰坡、雪松和通信阵列，作为最终挑战区。

## 路线设计

V0.1.6 设计了三条抵达最终目标的路线：

- 主路线：出生草地 -> 环形湖 -> 绳桥 -> 冰坡折返 -> 雪峰通信阵列。最清楚，也最稳定。
- 海岸路线：沙滩 -> 潮池踏石 -> 湿地 -> 隐藏洞口 -> 高地回主线。更探索向，回报是绕开部分爬坡。
- 山脊路线：隐藏路径 -> 晶体脊 -> 灰烬地 -> 玄武岩三角墙 -> 雪线。更短但视觉上更危险，地形阻挡更强。

scripts/star-trip/create-world-v016-assets.py

输出：

- `src/game-center/star-trip/assets/models/world/v0.1.6/world-v0.1.6.glb`
- `src/game-center/star-trip/assets/models/world/v0.1.6/world-v0.1.6.check.json`
- `src/game-center/star-trip/assets/models/world/v0.1.6/world-v0.1.6-reference-manifest.json`

- `output/star-trip/v0.1.6/world-v0.1.6-planet-view-0.png` 到 `world-v0.1.6-planet-view-5.png`

生成结果：

- 35 个 v0.1.6 资产：terrain 18 / landmark 9 / nature 8。
- `ST016_planet_terrain_shell` 是完整球面地形壳，不再依赖运行时单色基础球；它覆盖 100% 星球表面。
- 大型地块不是独立小盘子，也不是可见的“三角块”。草甸、湖盆、湖岸、沙滩、潮池、湿地、礁架、沙丘、火山灰原、晶体山脊、冰坡、雪顶、路径和起飞丘都切在同一个星球壳的三角面上；三角只是网格拓扑，玩家看到的是连续球面地貌。
- check JSON 用生成后的地形壳三角面面积做并集审计：`patch_surface_coverage_percent = 92.94`，真实覆盖超过 2/3 星球表面积。
- 地形壳使用 `ico_sphere` 网格，避免经纬网极点收束；当前升到 subdivision 6，主壳为 20480 个三角面，用更细粒度改善地貌边界锯齿。
- 星球半径范围约 `39.3463` 到 `50.1867`，高差约 `10.8404`，包含湖盆、雪峰、山脊和火山高地。
- 地形壳有 14 个实际出现的生态区材质，包含 grass、meadow、dark grass、sand、water、deep water、snow、ice、dark rock、basalt、violet、cinder、gold 等。
- check JSON 标记 `has_snow_water_beach_mountain = true`
- check JSON 标记 `has_three_routes_to_goal = true`
- 6 个旋转预览视角均为 1400x1400

运行时碰撞：

- `ST016_planet_terrain_shell` 是唯一运行时可走地形表面；大型地貌分区已经烘进这个球面壳，避免多个世界尺度 overlay mesh 互相遮挡或 raycast 命中错位。
- Pico 贴地时，从当前星球法线方向外侧发射 inward ray，和真实 terrain 三角面求交；命中点就是脚底表面，不再使用包围盒高度、经验系数或 `surfaceLift` 猜测地貌高度。
- 非地形素材会沿各自经纬度法线 raycast 到真实星球壳地面，再按少量 `radiusOffset` 放置，因此不再漂浮在数学球体半径上。
- 树、灯、晶体、岩石、塔、墙等实体模型继续使用轻量 collision body 阻挡角色；terrain 网格负责站立高度，不负责横向推出。
- E2E 验证所有放置对象 `allGroundedOnTerrain = true` 且 `floatingObjects = []`，出生点命中 `ST016_golden_grass_meadow` 且不会飞天，雪山顶命中 `ST016_snow_cap_peak` 且行走后仍停留在雪山网格表面，也验证 v0.1.5 火箭模型会把角色推出模型体积。
